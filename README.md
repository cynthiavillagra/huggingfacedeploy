# App básica con Gradio

Esta es una aplicación mínima creada con Gradio para desplegar en Hugging Face Spaces.

## ¿Qué hace?

La app pide un nombre y devuelve un saludo.

## Archivos principales

- `app.py`: contiene el código de la aplicación.
- `requirements.txt`: indica las librerías necesarias.

## Ejecutar localmente

```bash
pip install -r requirements.txt
python app.py
